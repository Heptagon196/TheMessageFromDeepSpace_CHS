# 《来自深空的讯息》正式翻译风格指南

本项目已完成 60 条样例审校并由用户定稿。所有正式译文必须与
`translations_sample_001.json` 的语感一致。`glossary.locked.json` 是人名、术语和专名的唯一权威来源；
`user_prompt.md` 是项目规则的完整版本，本文件提炼并行翻译时最容易漂移的要点。

## 0. 输出与标记是硬约束

- 输入、输出按 `text_index` 严格 1:1 对应，不合并、不拆分、不漏译。
- 原样保留并维持原有数量与相对顺序：`{SPEAKER_*}`、`{PART_nnn}`、`{SIG_nnn}`、
  `{SIG_Nnnn}`、`{PLAYER_NAME}`、`{DYN_n}`、`$anim...`、TMP 富文本、格式符及换行。
- `{SPEAKER_*}` 只提供口吻上下文，仍须留在 `translated_text` 中；运行时会移除或消费它。
- `{SIG_*}` 是玩家要自行解读的外星信号，绝不能猜义、解释或替换。
- `{DYN_n}` 是运行时数字、名称、路径或玩家数据。只翻译外围固定文字，不能翻译动态值。
- `translated_text` 只写中文译文，不附带英文；双语模式由插件运行时生成。

## 1. 总体文风

- 目标是自然、简洁、像中国人当场会说的话，不逐词照搬英语主语、从句和语序。
- 中文可以省略的主语、代词、所有格自然省略；长句可重组，但不得漏意。
- 使用地域中性的现代普通话。写“猫在哪里”，不写“猫在哪儿”；避免“啥、甭、整一个、老鼻子”等方言。
- 避免翻译腔和公文腔，例如机械使用“进行、取得、接下来的、这个结论、我相信你不会有问题”。
- 背景是 1973 年，不用网络流行语、饭圈词或明显现代互联网表达。
- 译完默读：如果不像人物能自然说出口，就继续改写。
- 保留原文的幽默、犹豫、停顿和简短回应；不擅自补解释。

## 2. 人物口吻

- `AKERS`（艾伦·埃克斯）：随意、爱开玩笑，短句多，口语自然，但不用地域方言。
- `COLLINS`（凯莉·柯林斯）：热情、敏锐、求知欲强；专业内容准确，表达仍然有现场感。
- `BAUTISTA`（布莱恩·巴蒂斯塔）：简短、克制、冷面幽默；不要把一两个词扩成长解释。
- `DOPPLER`（道格拉斯·多普勒）：温和、稳重、有领导者气质；不翻成官腔。
- `AUTO_LOG`：简洁、机械、像系统记录；代码/终端外观不代表应跳过翻译。
- `PILOT` / `CO_PILOT`：按原意自然翻译，不凭简短台词擅自增加性别信息。

## 3. 人名、称谓与 Translator

- 人名必须使用锁定译名。姓氏单独出现时也用词表对应形式，例如 Akers→埃克斯、Collins→柯林斯。
- `Dr. 姓氏` 统一为“姓氏博士”；自然对白可按语境省略无必要的敬称，但不能改人物关系。
- 对白中的玩家称呼已经提取为 `{PLAYER_NAME}`，绝不能写成固定称谓。
- 只有不会被玩家姓名动态替换的静态 UI `Translator` 才译为“翻译员”，不用“译者”。
- `translation` 指团队进行的项目/活动时译为“翻译工作”，普通动词按语境自然处理。

## 4. 科学、玩法与 UI

- 数学、物理、化学、生物、语言学采用中国大陆教材通行术语，以锁定词表为准。
- `signal`=“信号”，`transmission`=“传输/传输内容”，`message`=“讯息”，不可混用。
- `Act` 在进度 UI 中译为“幕”；`Act I` 等按上下文写成“第一幕”。
- `abundance`=“丰度”，`universal abundance`=“宇宙丰度”，`stable`=“稳定”。
- UI 按钮、标签和错误提示短而明确。代码风格控制台、启动日志、系统输出只要玩家看得到就必须翻译。
- 终端品牌名、文件名、程序名和数值如 `METEOR_OS`、`BAU_CORE_XXX.MOS` 保持原样；只翻译说明性英语。
- 成就名称可凝练但不改梗；成就说明必须完整传达达成条件。
- 谜题标题、歌曲名等作品性短标题可自然意译；不能把谜题答案或外星词义写进译名。
- 科学家猜测是玩家词典界面可见文本，应翻译；其中提到的未知外星词仍以 `{SIG_*}` 保留。

## 5. 标点与数字

- 中文正文使用全角标点和弯引号“ ”；内层引用可用‘ ’。游戏/篇目名需要时用《 》。
- 英文省略号统一为“……”，破折关系通常用“——”；不要随意增加感叹号。
- 中文与阿拉伯数字之间按自然排版留空格，例如“第 2 周”可按上下文写成“第二周”；长数字可用“18 万”这类自然表达，但公式、代码和动态占位符保持原样。
- `{PART_nnn}` 可随中文语序移动，但编号、数量和先后顺序不能改变。

## 6. 新实体与疑难原文

- 锁定表外的新专名默认保留英文并记入 `newterms`，不得自行创造音译。
- 原文偶有拼写错误、粘连或不完整句，应结合上下文还原明显意图，不在译文里复制无意义错误；不确定则忠实保守处理并记录复查。
- 不根据外星信号周围的英语上下文猜测其含义。

## 7. 已确认样例基准

翻译前完整阅读 `translations_sample_001.json`。特别参考其中：

- `Where's Bautista?` → “巴蒂斯塔人呢？”（自然，但不是地域方言）
- `I'll have to think on that.` → “我得琢磨琢磨。”（口语短句）
- `Tell me you have something.` → “总得有点发现吧。”（不逐词硬译）
- `Or persistent.` → “也可能只是不肯放弃。”（补足中文表达，不添加新事实）
- 长篇 Doppler 发言按中文语序重组，但所有 `{PART_nnn}` 与 `$anim...` 完整保留。
