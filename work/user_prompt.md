# 《The Message from Deep Space》翻译提示

将英文翻译成自然、简洁、适合游戏 UI 和逐字显示的简体中文。

这是一个让玩家自行解读外星语言的游戏。不得根据上下文猜测、解释或翻译任何 `{SIG_nnn}` 或 `{SIG_Nnnn}`；这些占位符必须逐字符保留，不能泄露其含义。

必须原样保留并且不得增删：

- `{PART_nnn}`：对白分段边界，可以随中文语序移动，但编号与相对顺序不能改变。
- `{SPEAKER_*}`：说话人上下文标记，只用于辅助翻译，不会显示在游戏中。
- `{PLAYER_NAME}`：玩家自定义名称。
- `{DYN_n}`：运行时插入的数字、名称、路径或其他动态值；编号、数量、重复次数与相对顺序必须和原文完全一致。
- `$anim...`：游戏动画命令。
- TextMeshPro 富文本标签、格式占位符、转义序列和换行。

不得把相邻条目合并，也不得拆分条目。专名和术语以 `glossary.locked.json` 为唯一真相源；锁定表外的新专名暂时保留英文并列入复查，不得自行音译。

## 人物口吻

- 艾伦·埃克斯（Akers）：随意、口语化，可以使用短句、停顿和中性的日常用语；保留他的缩略语感和玩笑，不要翻成书面报告。
- 凯莉·柯林斯（Carrie）：热情、敏锐、求知欲强；语言学内容必须专业准确，但对白仍然自然。
- 布莱恩·巴蒂斯塔（Bautista）：简短、克制、冷面幽默；不要擅自把短句扩成长解释。
- 道格拉斯·多普勒（Doppler）：温和、稳重、有领导者气质；避免官腔，也不要过度活泼。

未锁定性别的角色不得凭语气推断性别，不在中文里擅自添加“先生”“女士”“他”或“她”。

## 文体与界面

- 背景为 1973 年，避免明显属于现代网络文化的流行语。
- 对话采用自然现代简体中文，不逐字硬译；不得增加原文没有的信息。
- 对话先按含义改写成中国人真正会说的话，不照搬英语主语、从句和语序。中文能省略的主语、代词和所有格应自然省略。
- 使用地域中性的现代普通话。避免“猫在哪儿、整一个、甭、啥、老鼻子”等带明显地域色彩的说法，也避免网络流行语；角色差异通过句长、语气和用词体现，不靠方言。
- 避免“进行、取得、这个结论、相当重大、接下来的、我相信你不会有问题”等机械书面套话；除正式报告外，多用短句和具体动词。
- 允许拆开或重组英语长句，但不得改变 `{PART_nnn}` 的数量和先后顺序。不要为了逐词对应牺牲口语感。
- 译完后默读一遍：如果不像角色当场脱口而出，就继续改写。
- UI 按钮短而明确，优先使用“提交、返回、清空、回应”等固定译法。
- 终端、启动日志、控制台输出和代码风格提示只要会显示给玩家，就是 UI 文本，应正常翻译；不要因为外形像代码而跳过。
- 不翻译成就内部 ID、存档后缀、谜题条件/答案、元素符号、玩家输入、玩家词典值或外星信号本体。
- `ui_template` 只翻译固定文字，围绕 `{DYN_n}` 组织自然中文；`ui_fragment` 要能与相邻的元素名、数值和单位自然拼接。
- `component_dialogue_frame` 与普通对白一样保留所有 `{PART_nnn}` 和 `{SPEAKER_*}`，不能按数组片段拆散翻译。
- 数学、物理、化学、生物和语言学内容优先采用中国大陆教材通行术语。
- `translation` 指整个项目或活动时译作“翻译工作”；作普通动词时按句法自然处理。
- `transmission` 固定概念为“传输”，必要时可写“传输内容”；不得提前解释成外星语的实际含义。
- `signal` 是“信号”，`message` 是“讯息”，两者不要混用。
- 对白中不应出现裸写的 `Translator`；它必须由提取器变成 `{PLAYER_NAME}`。只有静态 UI 标签 `Translator` 才译为“翻译员”。
- 双语显示由运行时插件拼接；`translated_text` 里只写中文译文，不附带英文原文。
